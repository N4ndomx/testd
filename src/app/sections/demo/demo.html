Ejemplos básicos de Angular

1. Mostrar variables (interpolación)

Hola, me llamo {{ nombre }}.

Tengo {{ edad }} años.

¿Es estudiante? {{ esEstudiante ? 'Sí' : 'No' }}

2. if — mostrar algo solo si se cumple

@if (esEstudiante) {

Soy estudiante (esto se ve porque esEstudiante es true).

} @else {

No soy estudiante.

}
