# 13 · Práctica: CV con interpolación, `@for` y `@if`

> Objetivo: practicar **interpolación**, **arreglos** y **sentencias de control** (`@if`, `@for`) en una página de CV sencilla, con estilos básicos de Bootstrap. Archivo: `src/app/pages/cv/` (ruta `/cv`).

## Qué practica

| Concepto | Dónde se ve |
|---|---|
| Interpolación `{{ }}` | `{{ nombre }}`, `{{ email }}`, `{{ trabajo.puesto }}` |
| `@if` / `@else` | Badge "Disponible" / "No disponible" y "Sin habilidades" |
| `@for` con `track` | Lista de habilidades, tarjetas de experiencia, educación |
| `@for` con `$index` | Educación numerada (`1. …`, `2. …`) |
| `length` de un arreglo | `@if (habilidades.length > 0)` |

## Los datos (en `cv.ts`)

```ts
export class Cv {
  protected nombre = 'Ana García';
  protected profesion = 'Desarrolladora Web';
  protected email = 'ana@correo.com';
  protected telefono = '555 123 456';
  protected disponible = true;

  protected habilidades = ['Angular', 'TypeScript', 'HTML', 'CSS'];

  protected experiencia = [
    { puesto: 'Desarrolladora Frontend', empresa: 'Tech S.A.', anios: '2022 - 2024' },
    { puesto: 'Practicante Web', empresa: 'Startup X', anios: '2021 - 2022' },
  ];

  protected educacion = [
    { titulo: 'Ing. en Sistemas', escuela: 'UTCV', anios: '2018 - 2022' },
  ];
}
```

- `habilidades` es un **arreglo simple** (solo strings) → `@for` directo.
- `experiencia` y `educacion` son **arreglos de objetos** → `@for` + acceder a sus propiedades (`trabajo.puesto`).

## Las sentencias clave (en `cv.html`)

**`@if` + `@else` (badge):**
```html
@if (disponible) {
  <span class="badge text-bg-success">Disponible</span>
} @else {
  <span class="badge text-bg-secondary">No disponible</span>
}
```

**`@for` con `track` (habilidades):**
```html
@for (habilidad of habilidades; track habilidad) {
  <li class="list-group-item">{{ habilidad }}</li>
}
```

**`@for` con `$index` (educación numerada):**
```html
@for (estudio of educacion; track estudio.titulo; let i = $index) {
  <p>{{ i + 1 }}. {{ estudio.titulo }} — {{ estudio.escuela }}</p>
}
```

**`@for` + `length` (comprobación de vacío):**
```html
@if (habilidades.length > 0) {
  <ul>…lista…</ul>
} @else {
  <p>Sin habilidades registradas.</p>
}
```

## Estilos Bootstrap usados (los mismos que en el proyecto)

| Clase | Para qué |
|---|---|
| `container py-4` | Contenedor centrado con margen vertical |
| `text-center border-bottom pb-3` | Encabezado centrado y con línea separadora |
| `row` + `col-md-6` | Dos columnas en pantallas medianas (una debajo de otra en móvil) |
| `card mb-3` + `card-body` | Tarjetas de experiencia |
| `list-group` + `list-group-item` | Lista de habilidades |
| `badge text-bg-success` / `text-bg-secondary` | Etiqueta verde/gris para "Disponible" |
| `text-muted` | Texto gris claro |
| `h5` / `h6` | Títulos pequeños |

`cv.css` solo tiene una regla (`h1 { font-size: 1.75rem }`) — casi todo el estilo viene de Bootstrap.

## Cómo se ve

`ng serve` → `http://localhost:4200/cv` (o enlace "CV" del navbar).

## Tareas para el alumno (practicar)

1. **Interpolación:** agrega `nacimiento` y muéstralo con otra línea en el encabezado.
2. **Arreglo nuevo:** agrega `idiomas = ['Español', 'Inglés']` y muéstralos con `@for` en una sección.
3. **`@if` con `else`:** si `experiencia.length` es 0, muestra "Sin experiencia todavía."
4. **`$index`:** también numera las habilidades con `$index` (1. Angular, 2. TypeScript…).
5. **Reto:** agrega un campo booleano `freelance` y, con otro `@if`, muestra "Trabajo freelance" solo si es `true`.
6. **Reto extra:** agrega a `experiencia` un campo `actual` (booleano) y con `@if` pone un `badge` "Actual" junto a la empresa donde trabaja.
